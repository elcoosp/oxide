**Finding — cache eligibility excludes the vue/svelte/solid fixtures, and the
react p50 is 7.9 ms, not < 1 ms.** Two separate gaps, both already in the plan:

- **Only react serves an L0 hit at all.** The other three have no `dist/`
  state the cache path recognizes in this run (a fresh checkout — the harness
  built react, then reused whatever `dist/` existed for the others; this is a
  harness-ordering bug to fix in PERF-04's seeding, not a product bug).
- **The L0 p50 of 7.9 ms is far from §21's "< 1 ms".** The hit path is
  Rust-only (no JS), but each hit still re-serializes the response and walks
  the pipeline. PERF-04 (stale/SWR/single-flight) and PERF-07 (rkyv matcher)
  are the levers; the 1 ms target is a *target*, not a current claim.

## HMR (`bench:hmr`, smoke-app-react)

**Current: 0 / 8 iterations delivered an updated response — the dev watcher
fires (`INFO file change ev=Modified(…/page.tsx)`) but the change never reaches
the served HTML.** This is the known coarse-invalidation gap: `oxide dev`'s
loop calls `invalidate_framework_modules` but does not re-render the route.
SPEC-14 (HMR end-to-end) + PERF-08 (demand-graph invalidation) close it. The
harness is in place; re-run `./benchmarks/run.sh bench:hmr` after those land.
