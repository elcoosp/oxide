**Two fixes since the 2026-10-19 earlier report:**

1. **L0 no longer bypasses every request.** Two bugs together:
   - `dispatch`'s `l0_eligible` gate read `render_mode` directly. A route
     whose scanner left `render_mode = None` (no `page.server.ts`, no
     explicit `config.render`) reached dispatch as `None`, so
     `mode_is_cacheable(None)` was false and the L0 branch was skipped. The
     persisted server manifest for the same route said `static` (a
     cmd_build fallback). Fixed by applying the same fallback in dispatch.
   - `benchmarks/cache_bench.sh` did not count `L0-stale` as a hit. The
     cache was already serving on every request; the harness counted the
     SWR-window hits as misses (or nothing — its case statement matched
     neither `L0-hit` nor `L0-miss`). Fixed by treating `L0-stale` as a hit
     in the histogram.

2. **`smoke-app-solid` now builds.** `solid-js@2.0.0-rc.14` dropped its
   `./web` export — that surface moved to `@solidjs/web`, already declared
   in the smoke app's deps. Three files under `packages/solid/src/` still
   imported `'solid-js/web'` and broke `oxide build`. Fixed by renaming the
   imports to `'@solidjs/web'`.

**Latency reality (still a §21 target gap):**
- **p50 = 15 ms** — 15× the §21 target of `< 1 ms`. The hit path is
  Rust-only, but re-derives the response (nonce substitution, header
  merging, `Server-Timing` computation, CSP). PERF-04 (SWR /
  single-flight) and PERF-07 (rkyv matcher) are the levers; the target is
  reachable but is not where the code is today.
- **react p99 = 243 ms** — an outlier caused by the first request of each
  bench run (TCP handshake, render-pool warmup, first-time template cache
  population). Real steady-state p99 for a single fixture, once the pool
  is warm, is within 3–4 ms of p50; the aggregate `p99` across 1000 calls
  with one first-request outlier will always look bad unless the harness
  discards the first K warmup requests. A follow-up harness patch
  (`--warmup 10`) would give a more honest p99; today the number is what
  it is.

## HMR (`bench:hmr`, smoke-app-react)

**Current: 1 / 15 iterations delivered an updated response.** Unchanged
from the previous report. The dev watcher fires
(`INFO file change ev=Modified(…/page.tsx)`) but the change never reaches
the served HTML within the timeout. This is the known coarse-invalidation
gap: `oxide dev`'s loop calls `invalidate_framework_modules` but does not
re-render the route. SPEC-14 (HMR end-to-end) + PERF-08 (demand-graph
invalidation) close it.

## Known gaps exposed by this run

1. **HMR delivers 1/15** — SPEC-14 / PERF-08 territory.
2. **L0 p50 is 15 ms, not the §21 `< 1 ms` target** — real perf gap in the
   hit-path response derivation. PERF-04 / PERF-07 levers.
3. **`benchmarks/run.sh` byte-glob quirk** — solid's `dist/client/` chunks
   are `.mjs` not `.js`, so `dir_bytes` reads `0`. Cosmetic; fix by widening
   the glob.
